Ringkasan Materi: Algoritma

MGMP Oryza Sativa

Algoritma adalah langkah-langkah sistematis yang digunakan untuk menyelesaikan suatu masalah atau tugas tertentu.

1 Deskripsi Tertulis

Cara paling sederhana menggunakan kalimat sehari-hari berurutan. Contoh: 1. Isi ketel, 2. Rebus air, 3. Seduh kopi.

2 Flowchart (Bagan Alir)

Menampilkan algoritma dalam bentuk diagram visual menggunakan simbol baku (Oval=Mulai/Selesai, Jajar Genjang=Input/Output, Persegi=Proses).

3 Pseudocode

Kode semu menyerupai bahasa pemrograman asli untuk komputer. Menggunakan instruksi khusus seperti: SEND, RECEIVE, SET.

Pengaturan Google Sheets Guru

Masukkan URL Web App dari Google Apps Script agar data lembar kerja murid dapat terekam secara otomatis di Google Spreadsheet Ibu Hidayah Nurrahmadini.

Contoh Kode Google Apps Script (doPost):

function doPost(e) {

  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

  var d = JSON.parse(e.postData.contents);

  sheet.appendRow([new Date(), d.name, d.cls, d.absen, d.selectedMood, d.task1Act, d.steps, d.flowchart, d.quizAnswer, d.isQuizCorrect ? "BENAR" : "SALAH", d.ref1, d.ref2, d.ref3]);

  return ContentService.createTextOutput("OK");

}
